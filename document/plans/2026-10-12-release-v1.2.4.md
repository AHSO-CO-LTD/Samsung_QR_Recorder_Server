# Kế hoạch phát hành v1.2.4

Trạng thái: Ready for Release

## Mục tiêu

- Phát hành quyền quản lý đăng ký và thêm máy cho ADMIN tương đương DEV.
- Giữ các lệnh điều khiển máy là chức năng chỉ dành cho DEV.
- Đồng bộ phiên bản toàn monorepo từ 1.2.3 lên 1.2.4.
- Tạo GitHub Release và bộ cài Windows qua workflow hiện có.

## Phạm vi được duyệt

- Backend: cho phép ADMIN truy cập các API đăng ký, cấp phép, duyệt, từ chối và tạo máy trực tiếp.
- Frontend: hiển thị các thao tác tương ứng cho ADMIN; không mở quyền gửi lệnh máy.
- Cập nhật package manifests, package lock, API fallback version, README và CHANGELOG.
- Thêm PROJECT_PROFILE.md được tạo trong giai đoạn khảo sát.
- Chạy `npm run check` trước khi phát hành.
- Commit và push nhánh `setup`; tạo và push tag `v1.2.4`; theo dõi GitHub Actions.

## Ngoài phạm vi

- Không thay đổi mô hình dữ liệu hoặc migration.
- Không thay đổi ngày hiệu lực cấp phép `DEFAULT_RELEASE_DATE`.
- Không đưa thay đổi sinh tự động có sẵn trong `frontend/next-env.d.ts` vào commit.
- Không mở quyền gửi lệnh máy cho ADMIN.

## Các bước

- Done: khảo sát Git, kiến trúc release và vị trí phiên bản.
- Done: xác nhận phiên bản và phạm vi phát hành.
- Done: cập nhật source, phiên bản và tài liệu.
- Done: `npm run check` (Prisma validate; build Shared, Backend, Frontend và Electron).
- In Progress: rà soát staged diff, commit và push.
- Pending: tạo tag, theo dõi workflow và xác nhận artifact.

## Rủi ro và giảm thiểu

- Sai phạm vi quyền: giữ toàn bộ API/UI gửi lệnh máy DEV-only và rà soát diff trước commit.
- Đưa nhầm file người dùng vào commit: stage theo danh sách tệp cụ thể, loại `frontend/next-env.d.ts`.
- Build/release lỗi: chỉ tạo tag sau khi `npm run check` thành công; theo dõi workflow đến trạng thái cuối.

## Definition of Done

- Phiên bản 1.2.4 đồng bộ tại mọi manifest thuộc dự án và tài liệu phát hành.
- ADMIN có luồng thêm/đăng ký máy đã duyệt; lệnh máy vẫn DEV-only.
- `npm run check` thành công.
- Commit và tag `v1.2.4` có trên origin.
- GitHub Release được publish với bộ cài Windows và blockmap.
